# Battle of the Bands: Streaming Edition

A fictional, Spotify-like music streaming platform used as a learning
project for multi-cloud Terraform. All providers, resources, and data are
placeholders — see [.claude/business-rules.md](.claude/business-rules.md)
for the full architecture rules, and [.claude/CLAUDE.md](.claude/CLAUDE.md)
for how this project is developed.

- **AWS** — audio ingest & storage
- **Azure** — user accounts & playlists
- **GCP** — listening analytics & charts

## Structure

- `modules/` — reusable Terraform modules, one per cloud domain
- `envs/dev` / `envs/prod` — environment root configurations, each wiring
  the shared modules with environment-specific values
